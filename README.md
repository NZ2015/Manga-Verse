
# MangaVerse AI

MangaVerse AI est une plateforme indépendante de création assistée par intelligence artificielle.

## Fonctionnalités prévues

- Création automatique de mangas.
- Création de livres, films et séries.
- Création et personnalisation de personnages.
- Construction d'univers fictifs.
- Génération de scénarios et de dialogues.
- Création de pages et de cases de manga.
- Édition des propositions de l'IA.
- Choix du style noir et blanc ou couleur.
- Gestion des chapitres et des storyboards.

## Technologies

- HTML5
- CSS3
- JavaScript
- API d'intelligence artificielle
- Backend sécurisé à venir

## Organisation

- `index.html` : tableau de bord.
- `studio.html` : création de projets.
- `editor.html` : modification des créations.
- `characters.html` : gestion des personnages.
- `world.html` : construction des univers.
- `story.html` : création des histoires.
- `chapters.html` : gestion des chapitres.
- `storyboard.html` : organisation des cases.
- `css/` : styles.
- `js/` : fonctionnalités.
- `data/` : données initiales.
- `images/` : illustrations et ressources visuelles.

## Démarrage

Ouvrir `index.html` avec un navigateur ou déployer le site sur un hébergement statique.

## Important

La génération réelle par IA nécessite un serveur et une API sécurisée.
Les données actuellement enregistrées dans le navigateur ne sont pas encore synchronisées entre les appareils.

## Projet indépendant

MangaVerse AI est un projet indépendant.
